# Course Reflection
## How  i managed to overcome the difficult concept in the course
Navigating asynchronous JavaScript, RESTful API integrations, and relational database schema design presented a steep learning curve. The most difficult concept for me was mastering asynchronous data flows and error handling using `async/await` alongside relational database foreign key cascading. I overcame this by breaking down complex code blocks into smaller helper functions, testing each API endpoint step-by-step in the browser console, and visualizing state changes across local arrays and server responses.

## part of my custom I would improve
Based on the feedback received during earlier project milestones, I would improve my capstone's modular code organization and error notification messaging, ensuring cleaner separation of concerns between DOM rendering utilities and asynchronous network handlers. 

## what i would learn or explore next
Moving forward, I plan to dive deeper into cloud infrastructure orchestration, exploring containerization with Docker, deploying applications on Microsoft Azure, and implementing advanced automated testing frameworks to harden full-stack architectures.
